HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

HOW TO PUBLISH ON GITHUB PAGES
1. Open your website repository on GitHub.
2. Replace the old index.html with this index.html.
3. Upload favicon.svg into the same repository folder as index.html.
4. Commit the changes and wait for GitHub Pages to rebuild the site.
5. Refresh the live site using Ctrl+F5.

IMPORTANT — CONTACT FORM EMAIL
The contact form currently submits to FormSubmit for saad@growmatic.pro. FormSubmit may require an initial activation/confirmation email to be approved for that inbox. After publishing, submit a test message and check the inbox and spam folder. Do not assume delivery is working until that test arrives.

LIMITATION TO BE CLEAR ABOUT
This package is the updated static frontend. It does not yet include a custom server backend, database, or admin dashboard. GitHub Pages cannot run a server-side backend. Those requirements need a separate backend host and database, plus secure admin authentication. Do not advertise database/admin functionality as active until that is implemented and deployed.
